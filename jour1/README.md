# Jour 1

## Contenu

- `cours-rest-api.md` : cours sur HTTP et l'anatomie des messages HTTP (requêtes, réponses, headers, status codes)
- `exo-python/` : exercices Python (bases du langage, un fichier `.txt` d'énoncé et un fichier `.py` de correction pour chaque exercice)

## Environnement

Un environnement virtuel Python est disponible à la racine du projet (`venv/`).

Activation sous PowerShell :

```
..\venv\Scripts\Activate.ps1
```

Activation sous Git Bash :

```
source ../venv/Scripts/activate
```
